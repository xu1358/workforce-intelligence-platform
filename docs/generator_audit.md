# Version 1 Termination Generator Audit

## Purpose

This audit examines how Version 1 of the Workforce Intelligence Platform generates employee termination outcomes and dates.

The objective is to distinguish:

- Variables that directly determine termination
- Relationships produced indirectly by the generation sequence
- Intentional synthetic assumptions
- Accidental artifacts that models may learn
- Requirements for the Version 2 hazard design

No production generator logic was changed during this audit.

## Generator Scope

The project contains two employee generators:

| Generator | Purpose | Employee count |
|---|---|---:|
| `src/generate_employees.py` | Small teaching and validation sample | 50 |
| `src/generate_full_workforce.py` | Main portfolio workforce dataset | 10,000 |

The current portfolio data in `data/raw/employees.csv` was generated by `generate_full_workforce.py`. Therefore, the production audit focuses on that file.

## Production Termination Function

The production function receives only:

- `hire_date`
- `department_id`
- `location_id`

It does not receive:

- Performance history
- Compensation history or growth
- Promotion history
- Training participation
- Manager changes
- Transfer history
- Job level
- Employment type
- Education
- Age

## Current Eligibility Rules

Only individual contributors are passed to `choose_termination()`.
