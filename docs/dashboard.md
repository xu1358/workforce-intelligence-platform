# Workforce Intelligence Dashboard

## Purpose

The interactive dashboard provides a decision-support interface for the Workforce Intelligence and Retention Decision Platform.

The application is built with Streamlit and uses dashboard-ready datasets generated by the project's data layer.

## Run the dashboard

Activate the project virtual environment and build the latest dashboard datasets:

`python src/build_dashboard_data.py`

Then start the dashboard:

`python -m streamlit run dashboard/app.py`

## Dashboard sections

### Overview

The Overview page presents high-level workforce KPIs, including:

- Active headcount
- 2025 turnover rate
- Open requisitions
- Total applications
- Hired applications
- Retention snapshot population
- High-risk employee count

It also displays department headcount and retention-risk distributions.

### Workforce

The Workforce page presents:

- Active headcount by department
- Active headcount by location
- Workforce percentage distributions

### Recruiting

The Recruiting page presents:

- Recruiting outcomes by application source
- Hire rates by application source
- Job requisition counts
- Target headcount
- Average requisition days open

### Retention Risk

The Retention Risk page presents:

- Employee retention-risk rankings
- Low-, Medium-, and High-risk segments
- Attrition risk-score distributions
- Department filters
- Region filters
- Risk-segment filters

The risk scores are generated for the full retention snapshot population for prioritization purposes.

They should not be interpreted as unbiased model-performance estimates.

### Model Performance

The Model Performance page compares:

- Logistic Regression
- Random Forest
- Gradient Boosting

The selected model is chosen primarily using PR-AUC.

The page also presents:

- Precision
- Recall
- ROC-AUC
- PR-AUC
- Recommended classification threshold
- Medium-risk threshold
- High-risk threshold

Model-performance metrics are based on the held-out test set.

## Risk interpretation

Retention predictions are based on synthetic data.

Risk scores are intended for relative prioritization.

They should not be interpreted as:

- Exact real-world probabilities
- Causal relationships
- Automated employment decisions

A production HR analytics system would require additional privacy, fairness, governance, security, monitoring, and human-review controls.
